Here are the most common real-world scenarios where missing cleanup in useEffect causes serious issues, explained with practical examples:

1. API Request Race Conditions

useEffect(() => {
  let isMounted = true;
  
  fetch('/api/data')
    .then(res => res.json())
    .then(data => {
      if (isMounted) setData(data); // Only update if component is mounted
    });

  return () => {
    isMounted = false; // Cancels the state update if component unmounts
  };
}, []);
Problem Without Cleanup:

User navigates away while request is pending

Response arrives later and tries to update unmounted component

Causes "Can't perform state update on unmounted component" warning

2. WebSocket Connections

useEffect(() => {
  const socket = new WebSocket('wss://api.example.com');

  socket.onmessage = (event) => {
    updateLiveData(JSON.parse(event.data));
  };

  return () => {
    socket.close(); // Critical!
  };
}, []);
Problem Without Cleanup:

Socket remains open after component unmounts

Wastes server resources

May receive unwanted messages that try to update non-existent state

3. setInterval Memory Leaks

useEffect(() => {
  const timer = setInterval(() => {
    fetchUpdates();
  }, 5000);

  return () => clearInterval(timer);
}, []);
Problem Without Cleanup:

Interval keeps running forever

In a dashboard with multiple instances, you'll have dozens of intervals

Drains battery on mobile devices

Causes unnecessary API calls

4. Analytics Event Listeners

useEffect(() => {
  const trackScroll = () => {
    analytics.track('page_scroll', { position: window.scrollY });
  };

  window.addEventListener('scroll', trackScroll);
  
  return () => {
    window.removeEventListener('scroll', trackScroll);
  };
}, []);
Problem Without Cleanup:

Keeps tracking scroll events even on other pages

Floods analytics with incorrect data

Wastes CPU cycles processing unnecessary events

5. Third-party Library Initialization

useEffect(() => {
  const map = new MapLibrary('#map-container', {
    /* config */
  });

  return () => {
    map.destroy(); // Library-specific cleanup
  };
}, []);
Problem Without Cleanup:

Map instances pile up in memory

May cause visual glitches if reinitialized

Some libraries throw errors when multiple instances exist

6. Video/Audio Players

useEffect(() => {
  const video = document.getElementById('video');
  video.play();

  return () => {
    video.pause();
    video.currentTime = 0;
  };
}, []);
Problem Without Cleanup:

Audio keeps playing after leaving page

Wastes bandwidth streaming content

Poor user experience

7. Form Validation Listeners

useEffect(() => {
  const form = document.getElementById('checkout-form');
  const validate = () => { /* validation logic */ };

  form.addEventListener('input', validate);

  return () => {
    form.removeEventListener('input', validate);
  };
}, []);
Problem Without Cleanup:

Validation runs even when form isn't visible

Can interfere with other forms on page

May cause unexpected validation errors

Real Project Impact Checklist
Memory leaks: Components removed but their callbacks still reference memory

Performance degradation: Multiple duplicate listeners/processes running

UI inconsistencies: Old component logic affecting new components

Resource waste: Unnecessary network requests, CPU usage

Bug multiplication: Strange behaviors that are hard to reproduce






Pro Tip: Always ask:

"Does this effect create something persistent?"

"What needs to happen when this component goes away?"

"Could this continue working when it shouldn't?"
