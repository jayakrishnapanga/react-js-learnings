2. flex-flow
Purpose:
Shorthand for flex-direction + flex-wrap in one line.

When to Use It:
✅ Cleaner Code

Combines two properties for brevity.
/* Without flex-flow */
.container {
  flex-direction: row;
  flex-wrap: wrap;
}

/* With flex-flow */
.container {
  flex-flow: row wrap; /* Direction + wrap */
}
